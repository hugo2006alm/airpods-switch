Experimental Windows x64 alpha: guided radio/AirPods/output/transport setup, actionable
switch offers, explicit recovery after sleep or device loss, local redacted diagnostics
export, process app-ID audio correlation, and versioned binary/source packages.

Extract the entire Windows ZIP and launch `tray/AirPodsSwitch.Tray.exe`; see
`START-HERE.md`. CLI tools are under `diag/`. Runtime dependencies and notices are bundled.
The matching source ZIP and SHA-256 checksums accompany the binaries.

Hardware switching remains unverified. Source/list refresh query payloads are still
unestablished; stale observations suppress switching. A compatible existing control
driver or a working experimental direct L2CAP path is required. No driver is installed,
no Android/root modifications are supplied, and DID is never changed automatically.
Binaries are unsigned. This is a draft prerelease for owner review, not a stable release.
